Typical workflow
  1. Find imagery: set the area and dates, preview clear scenes, download.
  2. The download appears in Contents as a layer.
  3. Index analysis: compute NDVI, NDWI, NDBI… Each result is a new layer.
  4. Right-click a layer → Export as GeoTIFF, PNG or Shapefile.
